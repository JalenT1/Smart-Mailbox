# Smart Mailbox System
A Raspberry Pi smart mailbox system that detects when the mailbox is opened/closed or when the mailbox is emmpty or mail arrived, and sends updates to AWS IoT and triggers email notificaitons

## Features
- Detects when mail opens/closes
- Detects when new mail is placed or if mailbox is empty
- Publishes the sensor data to AWS IoT
- Email notifications

## Hardware Requirements
- Raspberry Pi
- IR Sensor
- Door Sensor
- Wires
