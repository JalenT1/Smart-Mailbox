# Smart Mailbox System
By Jalen Tottress and Olasubomi Rufai

A Raspberry Pi smart mailbox system that detects when the mailbox is opened/closed, when the mailbox is empty or mail arrived, and sends updates to AWS IoT and triggers email notifications
- For Setup Guide visit the docs folder

## Features
- Detects when mail opens/closes
- Detects when new mail is placed or if mailbox is empty
- Publishes the sensor data to AWS IoT
- Email notifications

## Hardware Requirements
- Raspberry Pi
- IR Sensor
- Door Sensor
- Wires
